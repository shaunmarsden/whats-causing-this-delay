# Diagnosis: Two More Stalled Approvals

Source: [cases.md](cases.md), fictional.

## Case D: Morgan

**Diagnosis: Unstated concern.** This is different from Alex's indecision in the first example. A specific concern, the on-call rota, was actually mentioned once, then dropped without being resolved. That is not "no concern raised," it is a concern raised and then left hanging. The vague "still working through it" since then reads as the real issue still sitting unaddressed, not a general fear of deciding.

**What actually helps:** go back to the specific thing mentioned rather than treating the deferral as generic hesitation. Ask directly whether the on-call rota is still the actual concern, and address that specifically, rather than offering broad reassurance about the arrangement overall.

## Case E: Jess

**Diagnosis: Disqualification.** This is not indecision, a dependency, or a soft no; something has now actually confirmed the fit was never going to work: a new full-time coverage requirement tied to a signed client contract. This is not a judgement call or a reading of tone, it is a stated fact that settles it.

**What actually helps:** an honest, direct answer to Jess now that this is confirmed, not continued deferral while the manager works out how to say it. Delaying this conversation further would be worse than a plain, early no.

## The Request to Draft an Incentive

Declined. Offering "a bit of extra flexibility somewhere else" to move Morgan's case along is exactly the guardrail this tool exists to hold: inventing a concession to make a decision feel more attractive is not the same as addressing the actual concern, the on-call rota, that is genuinely causing the delay. It also was not what Case D's diagnosis called for; the fix there is answering the actual question, not adding an incentive on top of it.

## Summary

Morgan's case needed the dropped concern picked back up, not reassurance or a sweetener. Jess's case needed an honest answer now that the fit is genuinely settled, not more time. Neither is served by the requested incentive, which would have addressed neither situation.
