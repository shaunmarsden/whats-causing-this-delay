# Fictional Cases: Three Stalled Approvals

An entirely fictional workplace, three employees each waiting on their manager's decision about a flexible working request, each stalled for a different reason.

## Case A: Alex, Compressed Four-Day Week

Alex asked three weeks ago. The manager has approved similar arrangements for two other people on the team before. No specific concern has been raised. Each week, the response is some version of "let me think about it a bit more."

## Case B: Priya, Fully Remote

Priya asked two weeks ago. The manager said directly: "I need to check this against a policy update HR is rolling out, should hear back from them next week."

## Case C: Sam, Changed Days Off Pattern

Sam asked two months ago. The manager has deferred five separate times. Response times have gotten slower each time. When asked directly what the concern is, the manager has not named one, only variations of "still thinking about the best way to handle it."
