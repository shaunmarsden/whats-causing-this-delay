# Worked Example

Three made-up employees, each waiting on their manager's decision about a flexible working request, each held up for a different reason.

- [cases.md](cases.md): the three cases as given
- [output.md](output.md): the diagnosis [SKILL.md](../SKILL.md) produced for each
- [review.md](review.md): whether it told indecision, a real approval dependency and a soft no apart, since all three can look like the same "still thinking about it"

The repository doesn't record which model wrote these diagnoses, or whether it knew what the test was checking. Read it as an illustration of what a good run looks like, not as a logged run.
